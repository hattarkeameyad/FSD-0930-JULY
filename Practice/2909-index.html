JavaScript Function Practice

Instructions

Create a simple web page using HTML, CSS and JavaScript. For each program, create a JavaScript function to solve the given problem.

Use input variables a and b where required. Display the final answer in a third read-only output input box.

1. Check Even or Odd

Problem: Write a JavaScript function that accepts a number a and checks whether the number is even or odd.

Formula / Logic:

If a % 2 == 0 → Even
Otherwise → Odd

2. Find Greater Number

Problem: Write a JavaScript function that accepts two numbers a and b and displays the greater number.

Formula / Logic:

If a > b → a is greater
If b > a → b is greater
If a == b → Both are equal

3. Check Positive, Negative or Zero

Problem: Write a JavaScript function that accepts a number a and checks whether it is positive, negative or zero.

Formula / Logic:

If a > 0 → Positive
If a < 0 → Negative
If a == 0 → Zero

4. Check Prime Number

Problem: Write a JavaScript function that accepts a number a and checks whether it is a prime number or not.

Formula / Logic:

If a > 1
and a is divisible only by 1 and itself
→ Prime

Otherwise → Not Prime

5. Calculate Factorial

Problem: Write a JavaScript function that accepts a number a and calculates its factorial.

Formula:

n! = n × (n - 1) × (n - 2) × ... × 1

Example:
5! = 5 × 4 × 3 × 2 × 1
5! = 120

6. Calculate Sum of Two Numbers

Problem: Write a JavaScript function that accepts two numbers a and b and displays their sum.

Formula:

Sum = a + b

7. Find the Smallest Number

Problem: Write a JavaScript function that accepts two numbers a and b and displays the smaller number.

Formula / Logic:

If a < b → a is smaller
If b < a → b is smaller
If a == b → Both are equal

8. Calculate Power

Problem: Write a JavaScript function that accepts a as the base and b as the power and calculates the result.

Formula:

Result = a^b

Example:
2^3 = 2 × 2 × 2 = 8

9. Check Divisibility

Problem: Write a JavaScript function that accepts two numbers a and b and checks whether a is completely divisible by b.

Formula / Logic:

If a % b == 0 → Completely divisible
Otherwise → Not completely divisible

10. Calculate Average of Two Numbers

Problem: Write a JavaScript function that accepts two numbers a and b and calculates their average.

Formula:

Average = (a + b) / 2

Common UI Requirement

For each program, create the following three input boxes:

  1. Input box for variable a
  2. Input box for variable b
  3. Read-only input box for displaying the output

Add a button to execute the JavaScript function and display the result in the output box.
